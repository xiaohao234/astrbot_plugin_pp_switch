# astrbot_plugin_pp_switch · 快捷人格切换

在聊天里一句话查看并切换 AstrBot 的人格（角色设定），无需 @ 机器人，切换后立即生效，并且不影响已有记忆。

## 版本历史

- **v1.0.5**（当前）
  - 新增 `base_persona`（底层人格）：在插件 WebUI 填写一个已在 AstrBot 创建的占位人格名（建议提示词写「请等待插件注入人格」并设为 AstrBot 默认人格）。配置后：该人格从 pp 列表中隐藏、不参与编号；新增 `pp 复位` 指令随时切回它（解除角色设定、保留记忆）。
  - 新增 `require_at`：群聊必须 @ 机器人（或唤醒前缀/引用）才能触发 pp，防止多个机器人同时响应同一条消息；私聊与 WebChat 不受影响。触发后由插件直接回复并停止事件传播，`pp` 不会被当作聊天内容发给 LLM。
- **v1.0.4**
  - 修复「切换人格后人设仍不生效」与「分段回复受影响」的共同根因：旧版本会向会话记忆注入一条假的 assistant 确认消息，模型会模仿这种括号动作式表达，导致回复风格偏离人设、并被分段回复切成奇怪碎片。现在**彻底不再写入任何记忆**，改为在切换后的前几次 LLM 请求中通过 `on_llm_request` 钩子临时附加人格强化提示（只改请求，不动记忆）。
  - 新增「切换后清空上下文」开关的完整语义：开启后每次切换人格（含重复切换同一人格）都会清空当前会话的 LLM 上下文，彻底杜绝残留；只清对话记忆，不删除平台聊天记录，WebUI 聊天记录仍可查看。

  - 修复序号徽章数字不居中的问题：改为按真实渲染墨迹绝对居中（同时修正「当前」标签文字的居中）。

## 功能

- 发送 `pp`（或 `人格切换`）生成一张人格列表图片：包含所有人格的名称、介绍与数字序号，底部附带帮助说明，并标记当前正在使用的人格。
- 发送 `pp <序号>`（例如 `pp 2`）把当前会话的 LLM 人格切换到对应人格。
- 支持 `pp 列表`、`pp 当前`、`pp 帮助`，以及直接写 `pp2` 这样的简写。
- 人格本体（名称、提示词、顺序）全部沿用 AstrBot WebUI「人格角色设定」里已有的配置，无需在插件里再维护一份。

## 兼容性

- AstrBot 版本：`>= 4.0.0`（开发与测试基于 v4.27.x）。
- 平台：QQ（aiocqhttp / NapCat）、Telegram、微信、WebChat 等所有平台适配器。
- 系统与架构：纯 Python + Pillow，适配 Linux（Debian/Ubuntu，含 ARM64 / aarch64）、macOS、Windows、以及 Docker 容器。

## 安装

### 1. 前置环境

插件本身只依赖 `Pillow`，AstrBot 在安装插件时会自动读取 `requirements.txt` 并安装，**通常无需手动装**。

在 Debian / Ubuntu（含 ARM 服务器）上，为了保证图片里的中文正常显示，建议安装一套中文字体（二选一）：

```bash
# 推荐：Noto CJK（覆盖中/日/韩，体积较小）
sudo apt-get update && sudo apt-get install -y fonts-noto-cjk

# 或：文泉驿（更小）
sudo apt-get install -y fonts-wqy-microhei
```

如果 AstrBot 跑在 Docker 里，请把上面的安装命令加到你的镜像构建（Dockerfile）里，或使用 `docker exec` 进入容器安装，然后**重启容器**。也可以不装字体，插件会自动探测系统里已有的中文字体；若一个都找不到，插件会自动回退为纯文本列表（功能不受影响，只是不生成图片）。

> 说明：`Pillow` 在 ARM64（aarch64）上有官方 manylinux wheel，`pip` 一般能直接装，不需要编译。若个别极老发行版需要从源码编译，请先执行
> `sudo apt-get install -y libjpeg-dev zlib1g-dev`。

### 2. 安装插件

三种方式任选其一：

1. **WebUI 插件市场**：AstrBot WebUI → 扩展 → 插件，粘贴本仓库地址或上传 zip 安装。
2. **手动解压**：把整个 `astrbot_plugin_pp_switch` 目录放进 AstrBot 数据目录下的 `data/plugins/`，然后重启 AstrBot。
3. **Git 克隆**：在 `data/plugins/` 下执行 `git clone <本仓库>`，再重启 AstrBot。

安装后在「插件」里启用本插件，并按需修改配置（无需重启即可在下次触发时生效；`trigger_words` 修改后需重启插件）。

## 使用

| 输入 | 作用 |
| --- | --- |
| `pp` 或 `人格切换` | 生成人格列表图片 |
| `pp 2` 或 `人格切换 2` | 切换到第 2 个人格 |
| `pp2` | 上面写法的简写 |
| `pp 列表` | 同上，查看列表图片 |
| `pp 当前` | 文字返回当前会话使用的人格 |
| `pp 复位` | 切回底层人格（需在插件 WebUI 配置 `base_persona`），解除角色设定 |
| `pp 帮助` | 文字返回使用说明 |

全部输入都**无需 @ 机器人**，也**不需要**任何唤醒前缀（群聊里开启 `require_at` 后则必须 @）。末尾带标点（如 `pp。`、`pp 2，`）也能正确识别。

## 配置项（WebUI 插件配置）

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `trigger_words` | `["pp", "人格切换"]` | 触发词列表，修改后重启插件生效 |
| `base_persona` | 空 | 底层人格名称：在 AstrBot 建好占位人格后填到这里，pp 列表中隐藏，`pp 复位` 切回 |
| `require_at` | `false` | 群聊必须 @ 机器人才触发 pp（防多 bot 误触发）；触发后不会发给 LLM |
| `admin_only` | `false` | 是否仅管理员可切换人格 |
| `intro_max_len` | `60` | 图片中每个人格介绍的最大字符数 |
| `image_width` | `900` | 图片宽度（像素），高度自适应 |
| `image_scale` | `2` | 图片超采样倍数，越大越清晰 |
| `font_path` | 空 | 自定义中文字体路径，留空自动探测 |
| `show_current` | `true` | 是否在图片中标记当前人格 |
| `help_lines` | 见下 | 图片底部帮助说明（每行一条） |
| `switch_handoff` | `true` | 切换后在接下来几次 LLM 请求中临时附加人格强化提示（不写入记忆） |
| `switch_clear_history` | `false` | 切换后清空当前会话的 LLM 上下文（对话记忆清零）；不影响聊天记录，WebUI 聊天记录仍可查看 |

`help_lines` 默认文案：

```text
发送 pp <序号> 切换到对应人格，例如：pp 2
发送 pp 或 pp 列表 查看人格列表
发送 pp 当前 查看当前人格
```

## 工作原理（为什么不会乱回复 / 乱 @ / 丢记忆）

1. **精确触发**：插件注册了一个自定义消息过滤器，只有“完全等于触发词”或“触发词 + 序号”这类消息才会唤醒并进入处理逻辑；其它任何消息（包括闲聊）都不会被本插件响应，更不会触发 @ 或胡言乱语。
2. **立即生效**：AstrBot v4 在每次 LLM 请求时，都会根据会话当前绑定的 `persona_id` 注入对应人格的系统提示词。本插件只更新该字段，因此下一条消息即刻使用新人格。
3. **不影响记忆**：切换只改 `persona_id`，不删除会话历史。默认开启的「人格强化」会在切换后的前几次 LLM 请求里临时附加一段强化提示（只改请求，不写入记忆），帮助模型立刻以新人格语气回应、避免旧人格残留；可通过 `switch_handoff` 关闭。
4. **不污染回复风格**：插件从不向会话记忆注入任何示例消息，模型的回复格式不会被打断或带偏，分段回复等后处理功能不受影响。
5. **会话隔离**：切换只作用于当前会话（群聊按群、私聊按人），不会波及其它会话；各会话的人格互不影响。

## 底层人格玩法（可选）

适合「平时是中性助手、聊天里随叫随换人格」的用法：

1. 在 AstrBot「人格角色设定」创建一个占位人格（如名称 `待注入`，提示词写 `请等待插件注入人格。`）；
2. 在 AstrBot 配置里把它设为**默认人格**；
3. 在本插件 WebUI 的 `base_persona` 填入 `待注入`。

效果：未切换时机器人是中性状态（等待注入）；`pp 复位` 随时切回中性；占位人格不出现在 pp 列表里。配合 `switch_clear_history` 可实现"每次切换都是全新开始"，配合默认的强化提示可实现"保留记忆地换人格"。

## 常见问题

**Q：图片里中文显示成方框怎么办？**
服务器缺少中文字体，安装 `fonts-noto-cjk` 或 `fonts-wqy-microhei` 后重启 AstrBot（Docker 需装进容器内）。

**Q：不想生成图片，想直接文字列表？**
如果 `Pillow` 缺失或中文字体缺失，插件会自动回退为纯文本列表，无需额外操作。

**Q：清空上下文后，聊天记录还能看吗？**
能。「清空上下文」只清 LLM 的对话记忆（conversation），聊天记录存在 AstrBot 独立的 `platform_message_histories` 表，完全不受影响。要在 WebUI 查看群聊/私聊记录，需在 AstrBot 配置 `provider_ltm_settings.group_message_history_enable` 开启记录功能，保留条数由 `group_message_history_max_cnt` 控制（默认 700，可按需改成 200）。

**Q：切换后感觉语气没立刻变？**
确认 `switch_handoff` 为开启（默认开启）。若仍不理想，可把 `switch_clear_history` 打开，切换即清空上下文、彻底杜绝残留（记忆会从头开始，聊天记录仍可查看）。

**Q：想限制只有管理员能切换？**
在插件配置里把 `admin_only` 设为 `true`。

## 更新 / 卸载

- 更新：在插件市场或仓库拉取最新版本，重启 AstrBot。
- 卸载：在插件管理里禁用并删除插件目录即可，不残留数据（切换行为本身保存在 AstrBot 的会话数据中，与插件无关）。
